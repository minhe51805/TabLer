# TableR v0.1.5

TableR v0.1.5 is one reliability-focused release train. It tightens the workflows already present instead of adding another broad set of unfinished features.

## Highlights

- deterministic virtualized grid selection, stable row mutation identity and grouped undo/redo
- complete persisted column layouts and bounded streaming CSV/TSV import plus CSV/JSONL export
- one parser-backed SQL safety decision shared by editor, AI and MCP, with request cancellation
- crash-safe editor text/cursor restore and scoped saved navigation
- OS-keyring storage for database and SSH secrets with v0.1.4b migration
- reviewed schema/admin SQL and direct versus effective PostgreSQL/MySQL privileges
- real provider-to-UI AI streaming, stop behavior, visible data consent and no scratch/tool leakage
- schema-first agent tools, primary-key row citations, chart reproduction specs and a fixed evaluation contract
- qualified Quick Switcher identities, 500-table ERD layout contract and bounded/revocable MCP/plugin access
- installer-only public release assets; SBOM, checksums and plugin registry remain internal workflow evidence

## Upgrade and recovery

The first v0.1.5 launch migrates legacy local metadata and creates a recovery snapshot before changing its storage schema. Database and SSH secrets move to the operating-system credential store and are not copied into JSON backups. See `docs/operations/STORAGE_RECOVERY.md` before manually changing application data.

## macOS

The macOS build is currently unsigned and not Apple-notarized. On Sonoma or newer, copy TableR to Applications, attempt one launch, then use System Settings > Privacy & Security > Open Anyway. If the quarantine prompt remains, run:

```bash
xattr -dr com.apple.quarantine /Applications/TableR.app
```

This is an operating-system override for an unsigned build, not a substitute for notarization. Verify that the download came from the official TableR release page.

## Release gates

The GitHub release must remain draft until the downloaded Windows, macOS and Linux assets, updater metadata, migration drill, accessibility scan and unsigned Sonoma behavior have all produced immutable evidence. The final release must be non-draft, non-prerelease and marked Latest only after that verification.
