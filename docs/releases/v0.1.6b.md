# TableR v0.1.6b

TableR v0.1.6b is a feature + hardening release on top of v0.1.6a: a large
convenience pass across the launcher, data grid, tabs, sidebar, ERD, and AI
panel, plus a stability/consolidation round (tool registry, bundle UI prefs,
a11y fixes, local usage stats).

## Highlights

### Launcher & connections

- Connection groups with color accents, drag-to-assign, collapse/expand, and
  history filters (engine/status/recent) in the launcher.
- Per-connection query timeout (1–600s) on `ConnectionConfig`, resolved at
  execution time across query/table/sandbox paths; carried by export/import.
- SQL favorites group under localStorage-backed folders with move-to-folder
  context menu and collapsible headers.

### Data grid

- Column pin/freeze: context-menu pin left/right, sticky columns with a
  divider shadow, persisted per table via the column-layout store, with a
  160px scrollable-width budget guard.
- Duplicate row, bulk set-value on a selection, and Markdown export.
- Manual "Generate test rows" from the grid toolbar or table context menu:
  client-side typed generator (locale pools + hints) → staged inserts →
  review modal → apply.

### Tabs & views

- Duplicate tab and a real two-pane split view: tabs drag between panes,
  the split collapses when empty.
- ERD export gains SVG alongside PNG/drawio (same renderer, 2x snapshot,
  standalone vector file named `<db>-erd-<date>.svg`); fixed a pre-existing
  `undefined rows` bug in PNG exports.

### Sidebar & data ops

- Multi-select tables (Ctrl/Shift-click) with a selection bar: bulk export
  into a directory (atomic `.part` → rename, per-table failures collected,
  cancellable) and a typed-phrase bulk drop with live row-count previews
  through the guarded structure-statements path.

### AI panel

- Image attach: up to 4 images per message, 5MB downscale, non-vision
  models warn instead of blocking.
- Agent tool executor refactored into a per-tool registry
  (`agent-tools/*.ts`) — the 2500-line switch is now orchestration only;
  behavior unchanged (94 executor tests + 14 eval goldens pass).
- Rules: "New rule" falls back to the global `<data_dir>/rules` root when
  no linked folder exists, so the feature works out of the box.
- Model picker: search box, "Free only" toggle, Free badge (`:free` suffix
  or all-zero pricing), and per-1M-token input/output/cache prices when the
  provider publishes them (OpenRouter).

### Workspace bundle & shell

- Workspace bundles now carry UI preferences: shareable `tabler.*`
  localStorage keys (connection groups, favorite folders, recents, column
  layouts, theme, shortcuts) export/import with a "UI Preferences"
  checkbox; safety/consent/per-device keys are excluded.
- Help menu: "Report an issue" and "Send feedback" open GitHub via the new
  `open_external_url` command (http(s)-only).
- Local-only usage counter: per-feature open counts in localStorage,
  readable and copyable in the About modal — no telemetry, nothing leaves
  the machine.
- F1 no longer hijacked inside Monaco (keeps its own command palette);
  Ctrl+/ unchanged.

### Accessibility & stability

- Launcher connection cards: `role=button` div with focusable descendants
  replaced by a stretched real button; rename/delete sit above it.
- WCAG AA contrast on the light preset: `tertiaryText` and muted/dim tokens
  darkened; "Create connection" primary button fill darkened.
- e2e `workspace-smoke` axe scan: zero serious/critical violations.
