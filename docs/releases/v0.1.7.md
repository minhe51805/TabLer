# TableR v0.1.7

TableR v0.1.7 ships the biggest agent and analytics milestone so far: rewind checkpoints for grid writes, a full metrics-board platform, a semantic glossary the agent can learn into, and a scheduled-run mode — plus a relicensing to AGPLv3 and a public website overhaul.

## Highlights

- rewind checkpoints for the DataGrid: encrypted pre-image capture plus a restore UI, so a destructive grid edit can be rolled back to its exact before state; a structured refusal layer with a 7-day TTL bounds what can be recovered
- metrics boards as a first-class surface: 4 new widget types, a visual query builder inside the widget editor, board-level `{{param}}` filters, drag/keyboard reorder, board zoom, auto-refresh countdowns, stale-data indicators, export preview, print view, activity log, templates gallery, and CSV/PNG/drill-down per widget
- agent learning loop (P8–P10): proactive insight cards with evidence, a learning pipeline that offers run findings for approval before writing them to memory, and a scheduler that runs saved agent tasks read-only through the panel's own loop with recorded outcomes
- semantic glossary + agent skills manager: `remember_term` writes durable semantics into a per-connection glossary (with a toast + activity signal so writes are observable), a master-detail SKILL.md manager with an editor for stored skills, and `origin:` provenance in MEMORY.md frontmatter separating agent-authored from user-authored notes
- durable-knowledge content gate: memory writes, glossary saves, and native memory-tool writes are rejected when they carry credentials or row identifiers — durable stores must hold semantics, not data
- SQL/editor ergonomics: `{{var}}` parameter placeholders in favorites and query tabs, markdown-fence unwrapping on paste for every engine, MongoDB `$`-operators no longer mistaken for params, and queue/edit-and-rerun prompts while the agent is mid-run
- export hardening: table/connection/bundle exports are encrypted with AES-256-GCM envelopes
- new engines: typesense, surrealdb, and weaviate join the registry as declarative-http plugin drivers; capability matrix raised through real transactions and server-side cancel probes; MSSQL `list_schema_objects` hardened for older servers
- onboarding tour: a first-run task funnel around the sample database with a docs link in the footer
- license change: TableR is now AGPL-3.0 (see LICENSE); the README badge follows

## Website

The public site was rebuilt around the agent story: a split-pane live-session demo, cinematic hero, mobile nav, per-engine docs pages with connection-URI placeholders, docs search, scroll-spy nav, print styles, OG metadata per page, and speed insights/analytics.

## Upgrade and recovery

Rewind checkpoints persist encrypted pre-images per scope and expire after 7 days. Agent memory now writes `origin:` into MEMORY.md frontmatter — entries without it are treated as agent-authored for backwards compatibility. See `docs/operations/STORAGE_RECOVERY.md` before manually changing application data.

## Release gates

The GitHub release must remain draft until the platform assets, updater metadata, and a checkpoint create → edit → restore smoke drill have produced immutable evidence. The final release must be non-draft, non-prerelease and marked Latest only after that verification.
